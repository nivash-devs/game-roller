# Game Roller

A black and white page that asks "Can I make this?" and shows a blank. At rest it shows one solid line. Press space and it rolls through about 90 real app names, like WhatsApp, Discord and Godot, and lands on Rubik's Cube.

Space rolls, R resets, M mutes.

Made for a build-in-public reel: roll, land, then build the app.
